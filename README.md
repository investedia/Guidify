# Guidify website

Static site for guidify.eu. Plain HTML, CSS and vanilla JavaScript, GitHub Pages compatible.

- `index.html` — homepage (nav, hero, products, about, contact, footer)
- `privacy.html`, `legal.html` — supporting pages (drafts)
- `styles.css` — design tokens on `:root`, components, responsive rules
- `script.js` — mobile menu, footer year, subtle reveal
- `assets/` — images
